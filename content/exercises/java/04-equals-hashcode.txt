title: Make two equal points one set entry
level: Easy
@@ task
A `HashSet` finds duplicates with `hashCode()` first and `equals()` second. Right now `Point` uses the default identity versions, so two points with the same `x` and `y` count as different, and the set ends up with 2 entries instead of 1.

Fill in the two methods in `Point` (you learned the recipe in *Object Internals & Primitives*, section "equals(), hashCode() and toString()"):

1. `equals(Object o)` is true when `o` is a `Point` with the same `x` **and** the same `y`. It must return `false` for `null`.
2. `hashCode()` must use the **same fields** as `equals`, so equal points have equal hash codes.

Run it: when all four printed lines match the expected output, the exercise is done.
@@ hint
**Hint 1 (idea).** Two points are "the same" when both coordinates match. `equals` answers that; `hashCode` must follow the same rule.

**Hint 2 (the four steps of equals).** Same object? return true. Not a `Point`? return false (this also covers `null`). Otherwise compare `x` and `y`. The starter has these steps as comments.

**Hint 3 (almost the answer).** `if (this == o) return true;` then `return o instanceof Point p && x == p.x && y == p.y;`. For the hash code: `return Objects.hash(x, y);`.

**If the output is wrong:** `2` on the first line means `equals` or `hashCode` is still the default; `false` on the second line means `hashCode` is missing or uses different fields; a crash on the third line means `equals` does not handle `null`.

import java.util.*;

public class Main {
    static class Point {
        final int x, y;
        Point(int x, int y) { this.x = x; this.y = y; }

        @Override public boolean equals(Object o) {
            // step 1: if (this == o) return true;
            // step 2: return false when o is not a Point (null is not a Point)
            // step 3: compare x and y
            return false;
        }

        @Override public int hashCode() {
            // use the same fields as equals: x and y
            return 0;
        }
    }

    public static void main(String[] args) {
        Set<Point> set = new HashSet<>();
        set.add(new Point(1, 2));
        set.add(new Point(1, 2));
        System.out.println(set.size());                                          // 1
        System.out.println(set.contains(new Point(1, 2)));                       // true
        System.out.println(new Point(1, 2).equals(null));                        // false
        System.out.println(new Point(1, 2).hashCode() == new Point(1, 2).hashCode());   // true
    }
}
@@ solution
import java.util.*;

public class Main {
    static class Point {
        final int x, y;
        Point(int x, int y) { this.x = x; this.y = y; }

        @Override public boolean equals(Object o) {
            if (this == o) return true;
            return o instanceof Point p && x == p.x && y == p.y;
        }

        @Override public int hashCode() { return Objects.hash(x, y); }
    }

    public static void main(String[] args) {
        Set<Point> set = new HashSet<>();
        set.add(new Point(1, 2));
        set.add(new Point(1, 2));
        System.out.println(set.size());                                          // 1
        System.out.println(set.contains(new Point(1, 2)));                       // true
        System.out.println(new Point(1, 2).equals(null));                        // false
        System.out.println(new Point(1, 2).hashCode() == new Point(1, 2).hashCode());   // true
    }
}
