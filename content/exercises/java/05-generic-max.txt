@@ task
You just learned that `<T extends Comparable<T>>` means "T must be able to compare itself", and that `compareTo` returns a positive number when this item beats the other.

Write the body of `maxOf`:
1. If the list is empty, throw `NoSuchElementException` (it is in `java.util`).
2. Start with `best = items.get(0)` (the first item).
3. Loop through every item. If `item.compareTo(best) > 0`, that item is bigger — update `best`.
4. Return `best` after the loop.

The method already has the right signature. You only need to fill in the body.
@@ hint
**Hint 1 (idea).** The signature `<T extends Comparable<T>>` promises that every item has a `compareTo` method. Walk the list once, keeping the largest item seen so far.

**Hint 2 (the tool).** `item.compareTo(best)` returns a positive number when `item` is larger than `best`. That is your condition for updating `best`.

**Hint 3 (shape).** Check empty first: `if (items.isEmpty()) throw new NoSuchElementException();`. Then: `T best = items.get(0); for (T item : items) { if (item.compareTo(best) > 0) best = item; } return best;`

@@ solution
import java.util.*;

public class Main {
    static <T extends Comparable<T>> T maxOf(List<T> items) {
        if (items.isEmpty()) throw new NoSuchElementException();
        T best = items.get(0);
        for (T item : items) {
            if (item.compareTo(best) > 0) best = item;
        }
        return best;
    }

    public static void main(String[] args) {
        System.out.println(maxOf(List.of(3, 9, 4)));                       // 9
        System.out.println(maxOf(List.of("pear", "apple", "zebra")));      // zebra
        try {
            maxOf(new ArrayList<Integer>());
            System.out.println("no error");
        } catch (NoSuchElementException e) {
            System.out.println("empty list");                              // empty list
        }
    }
}
