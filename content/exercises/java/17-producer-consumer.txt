title: Producer and consumer with a blocking queue
level: Medium
@@ task
A producer thread puts the numbers 1 to 5 into a small queue (room for 2), then puts `-1` as a "no more work" signal. The queue is already filled for you.

Write the **consumer** in `main`: keep taking numbers from the queue and add them up until you receive `-1`, then print `sum=<total>`.
@@ hint
`queue.take()` waits when the queue is empty, so no polling or `sleep` is needed. Loop: `int n = queue.take(); if (n == -1) break; sum += n;`.
@@ expect
sum=15
@@ starter
import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) throws InterruptedException {
        BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(2);

        Thread producer = new Thread(() -> {
            try {
                for (int i = 1; i <= 5; i++) queue.put(i);   // waits while the queue is full
                queue.put(-1);                                // poison pill: nothing more is coming
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
        producer.setDaemon(true);   // so a half-finished attempt cannot keep the program alive
        producer.start();

        int sum = 0;
        // TODO: take() numbers until you get -1, adding each one to sum

        System.out.println("sum=" + sum);   // sum=15
        producer.join(1000);
    }
}
@@ solution
import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) throws InterruptedException {
        BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(2);

        Thread producer = new Thread(() -> {
            try {
                for (int i = 1; i <= 5; i++) queue.put(i);   // waits while the queue is full
                queue.put(-1);                                // poison pill: nothing more is coming
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
        producer.setDaemon(true);   // so a half-finished attempt cannot keep the program alive
        producer.start();

        int sum = 0;
        while (true) {
            int n = queue.take();
            if (n == -1) break;
            sum += n;
        }

        System.out.println("sum=" + sum);   // sum=15
        producer.join(1000);
    }
}
