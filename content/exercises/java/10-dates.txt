title: Days between and day of the week

@@ task
You just learned that `LocalDate.parse` reads an ISO date string (`yyyy-MM-dd`), that `ChronoUnit.DAYS.between(from, to)` counts the days between two dates, and that `getDayOfWeek().toString()` gives the day name.

Write two methods:
- `daysBetween(from, to)`: parse both strings, then return `ChronoUnit.DAYS.between(a, b)`.
- `weekdayOf(date)`: parse the string, then return `getDayOfWeek().toString()`.
@@ hint
**Hint 1 (idea).** Both methods do the same two steps: parse the string into a `LocalDate`, then ask the date for the information you need.

**Hint 2 (the tools).** `LocalDate.parse("2024-01-01")` reads an ISO date. `ChronoUnit.DAYS.between(a, b)` returns a `long`. `.getDayOfWeek()` returns a `DayOfWeek` enum; `.toString()` gives `FRIDAY`.

**Hint 3 (shape).** `daysBetween`: `return ChronoUnit.DAYS.between(LocalDate.parse(from), LocalDate.parse(to));` — `weekdayOf`: `return LocalDate.parse(date).getDayOfWeek().toString();`

@@ solution
import java.time.*;
import java.time.temporal.ChronoUnit;

public class Main {
    static long daysBetween(String from, String to) {
        return ChronoUnit.DAYS.between(LocalDate.parse(from), LocalDate.parse(to));
    }

    static String weekdayOf(String date) {
        return LocalDate.parse(date).getDayOfWeek().toString();
    }

    public static void main(String[] args) {
        System.out.println(daysBetween("2024-01-01", "2025-01-01"));   // 366 (2024 is a leap year)
        System.out.println(daysBetween("2026-11-20", "2026-12-25"));   // 35
        System.out.println(weekdayOf("2026-11-20"));                   // FRIDAY
        System.out.println(weekdayOf("2000-02-29"));                   // TUESDAY
    }
}
