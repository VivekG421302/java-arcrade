@@ task
You just learned the stream pipeline: `filter` keeps items, `map` reshapes them, `sorted` orders them, and `Collectors.joining` stitches them into a string.

Write `shout(List<String> names)` as **one stream pipeline**:
1. Keep only names with **4 or more** letters (`filter`).
2. Turn them to **UPPER CASE** (`map(String::toUpperCase)`).
3. Sort them **alphabetically** (`sorted()`).
4. Join them with `", "` (`collect(Collectors.joining(", "))`).
@@ hint
**Hint 1 (idea).** Four stations on the belt: filter the short names out, shout the rest, sort, then join with a comma-space.

**Hint 2 (the tools).** `names.stream().filter(n -> n.length() >= 4).map(String::toUpperCase).sorted().collect(Collectors.joining(", "))`.

**Hint 3 (shape).** The whole method body is one `return` statement with the pipeline above.
@@ expect
ANITA, KABIR, RAVI, ZOYA
CCCC

@@ solution
import java.util.*;
import java.util.stream.*;

public class Main {
    static String shout(List<String> names) {
        return names.stream()
                .filter(n -> n.length() >= 4)
                .map(String::toUpperCase)
                .sorted()
                .collect(Collectors.joining(", "));
    }

    public static void main(String[] args) {
        System.out.println(shout(List.of("ravi", "li", "anita", "om", "zoya", "kabir")));   // ANITA, KABIR, RAVI, ZOYA
        System.out.println(shout(List.of("a", "bb", "cccc")));                              // CCCC
    }
}
