title: An LRU cache in a few lines
level: Medium
@@ task
A cache must not grow forever. An **LRU** (least recently used) cache throws away the entry nobody has touched for the longest time once it is full.

Make `LruCache` hold at most `capacity` entries. Reading an entry (`get`) counts as using it.

In the test the capacity is 2: after `a` and `b` are added, `a` is read, so adding `c` must evict `b`.
@@ hint
`LinkedHashMap` can keep entries in access order: `super(16, 0.75f, true)`. Then override `removeEldestEntry(Map.Entry<K,V> eldest)` and return `size() > capacity`. The class below extends `LinkedHashMap` for you.
@@ expect
null
1
3
2

@@ solution
import java.util.*;

public class Main {
    static class LruCache<K, V> extends LinkedHashMap<K, V> {
        private final int capacity;

        LruCache(int capacity) {
            super(16, 0.75f, true);
            this.capacity = capacity;
        }

        @Override protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
            return size() > capacity;
        }
    }

    public static void main(String[] args) {
        LruCache<String, Integer> cache = new LruCache<>(2);
        cache.put("a", 1);
        cache.put("b", 2);
        cache.get("a");          // "a" is now the most recently used
        cache.put("c", 3);       // full: the least recently used one ("b") must go
        System.out.println(cache.get("b"));   // null
        System.out.println(cache.get("a"));   // 1
        System.out.println(cache.get("c"));   // 3
        System.out.println(cache.size());     // 2
    }
}
