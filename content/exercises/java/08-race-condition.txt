title: Fix the lost updates
level: Medium
@@ task
You just learned that `synchronized` on a method locks on `this`, making the whole read-yield-write one locked step, and that readers of shared state also need the same lock.

Four threads each add 1000 to a shared counter, so the answer must be **4000**. Right now `increment()` reads the value, lets other threads run (`Thread.yield()`), then writes it back — so updates get lost.

Make `Counter` thread-safe by adding `synchronized` to both `increment()` and `get()`. Do not remove the `Thread.yield()` line.
@@ hint
**Hint 1 (idea).** The gap between reading and writing `value` lets another thread sneak in and read the same stale value. `synchronized` closes that gap.

**Hint 2 (the tool).** Add the keyword `synchronized` before `void increment()` and before `int get()`. Both use `this` as the lock, so they exclude each other.

**Hint 3 (shape).** `synchronized void increment() { ... }` and `synchronized int get() { return value; }` — that is all that changes.
@@ expect
4000
@@ starter
public class Main {
    static class Counter {
        private int value;

        // step 1: add synchronized here
        void increment() {
            int current = value;
            Thread.yield();          // another thread may run right here
            value = current + 1;
        }

        // step 2: add synchronized here too (readers need the same lock)
        int get() { return value; }
    }

    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        Thread[] threads = new Thread[4];
        for (int t = 0; t < threads.length; t++) {
            threads[t] = new Thread(() -> {
                for (int i = 0; i < 1000; i++) counter.increment();
            });
            threads[t].start();
        }
        for (Thread t : threads) t.join();
        System.out.println(counter.get());   // 4000
    }
}
@@ solution
public class Main {
    static class Counter {
        private int value;

        synchronized void increment() {
            int current = value;
            Thread.yield();          // another thread may run right here
            value = current + 1;
        }

        synchronized int get() { return value; }
    }

    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        Thread[] threads = new Thread[4];
        for (int t = 0; t < threads.length; t++) {
            threads[t] = new Thread(() -> {
                for (int i = 0; i < 1000; i++) counter.increment();
            });
            threads[t].start();
        }
        for (Thread t : threads) t.join();
        System.out.println(counter.get());   // 4000
    }
}
