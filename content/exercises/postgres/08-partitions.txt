title: Split a table by month
level: Hard
@@ task
`measurement` is one big table. Turn it into a table **partitioned by range** on `logdate`, with two partitions: `measurement_2024_01` (January 2024) and `measurement_2024_02` (February 2024). Partition bounds include the start and exclude the end.

The query that follows asks each row which partition it lives in (`tableoid::regclass`), so you should see 2 rows in January and 1 in February. A row for May has no partition, so the last line should print `23514`.
@@ hint
`CREATE TABLE measurement (...) PARTITION BY RANGE (logdate);` then `CREATE TABLE measurement_2024_01 PARTITION OF measurement FOR VALUES FROM ('2024-01-01') TO ('2024-02-01');` and the same for February. Create the partitions **before** the INSERT.
@@ expect
measurement_2024_01 | 2
measurement_2024_02 | 1
23514

@@ solution
CREATE FUNCTION attempt(stmt text) RETURNS text LANGUAGE plpgsql AS $$
BEGIN
  EXECUTE stmt;
  RETURN 'ok';
EXCEPTION WHEN OTHERS THEN
  RETURN SQLSTATE;
END $$;

CREATE TABLE measurement (
  logdate date NOT NULL,
  value   int
) PARTITION BY RANGE (logdate);

CREATE TABLE measurement_2024_01 PARTITION OF measurement FOR VALUES FROM ('2024-01-01') TO ('2024-02-01');
CREATE TABLE measurement_2024_02 PARTITION OF measurement FOR VALUES FROM ('2024-02-01') TO ('2024-03-01');

INSERT INTO measurement VALUES ('2024-01-10', 5), ('2024-01-20', 7), ('2024-02-03', 9);

SELECT tableoid::regclass AS partition, count(*) AS rows FROM measurement GROUP BY 1 ORDER BY 1;
SELECT attempt($$INSERT INTO measurement VALUES ('2024-05-01', 1)$$);     -- 23514 (no partition for May)
