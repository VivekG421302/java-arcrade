=== 13
S: A phrase is a palindrome if, after lowercasing it and removing every character that is not a letter or digit, it reads the same forwards and backwards. Return whether string `s` is a palindrome.
T: `s = "A man, a plan, a canal: Panama"` => `true`
T: `s = "race a car"` => `false`
T: `s = " "` => `true`
A: Two pointers from both ends. Skip non-alphanumeric characters on each side, compare the lowercase characters, and move inward. No extra string is built, so space is O(1).
C: new Solution().isPalindrome("A man, a plan, a canal: Panama") && !new Solution().isPalindrome("race a car") && new Solution().isPalindrome(" ")
```java
class Solution {
    public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
            while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
            if (Character.toLowerCase(s.charAt(l++)) != Character.toLowerCase(s.charAt(r--))) {
                return false;
            }
        }
        return true;
    }
}
```
=== 14
S: `numbers` is sorted in non-decreasing order. Return the 1-based indices `[i, j]` (with `i < j`) of the two numbers that add up to `target`. Exactly one solution exists and you may not reuse an element. Use only constant extra space.
T: `numbers = [2,7,11,15], target = 9` => `[1,2]`
T: `numbers = [2,3,4], target = 6` => `[1,3]`
T: `numbers = [-1,0], target = -1` => `[1,2]`
A: Start one pointer at each end. If the sum is too small, move the left pointer right; if too large, move the right pointer left. Sorting guarantees each move rules out a whole row of pairs.
C: A(new Solution().twoSum(new int[]{2,7,11,15},9)).equals("[1,2]") && A(new Solution().twoSum(new int[]{2,3,4},6)).equals("[1,3]") && A(new Solution().twoSum(new int[]{-1,0},-1)).equals("[1,2]")
```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int l = 0, r = numbers.length - 1;
        while (l < r) {
            int sum = numbers[l] + numbers[r];
            if (sum == target) return new int[]{l + 1, r + 1}; // 1-indexed
            if (sum < target) l++;
            else r--;
        }
        throw new IllegalArgumentException("no solution");
    }
}
```
=== 15
S: Return all unique triplets `[a, b, c]` from `nums` such that `a + b + c == 0`. The result must not contain duplicate triplets.
T: `nums = [-1,0,1,2,-1,-4]` => `[[-1,-1,2],[-1,0,1]]`
T: `nums = [0,1,1]` => `[]`
T: `nums = [0,0,0]` => `[[0,0,0]]`
A: Sort the array. Fix the first value `nums[i]`, then solve a two-sum with two pointers on the rest. Skip repeated values for `i`, `l` and `r` so no duplicate triplet is produced.
C: S(new Solution().threeSum(new int[]{-1,0,1,2,-1,-4})).equals("[[-1,-1,2],[-1,0,1]]") && S(new Solution().threeSum(new int[]{0,1,1})).equals("[]") && S(new Solution().threeSum(new int[]{0,0,0})).equals("[[0,0,0]]")
```java
import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) break;                          // smallest value positive: no zero sum
            if (i > 0 && nums[i] == nums[i - 1]) continue;   // skip duplicate anchors
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < 0) l++;
                else if (sum > 0) r--;
                else {
                    res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    l++; r--;
                    while (l < r && nums[l] == nums[l - 1]) l++;
                    while (l < r && nums[r] == nums[r + 1]) r--;
                }
            }
        }
        return res;
    }
}
```
=== 16
S: `height[i]` is the height of a vertical line at position `i`. Pick two lines that, together with the x-axis, form a container holding the most water, and return that maximum area.
T: `height = [1,8,6,2,5,4,8,3,7]` => `49`
T: `height = [1,1]` => `1`
T: `height = [4,3,2,1,4]` => `16`
A: Start with the widest container (both ends). The area is limited by the shorter line, so moving the taller line can never help; move the shorter one inward and keep the best area seen.
C: new Solution().maxArea(new int[]{1,8,6,2,5,4,8,3,7})==49 && new Solution().maxArea(new int[]{1,1})==1 && new Solution().maxArea(new int[]{4,3,2,1,4})==16
```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, best = 0;
        while (l < r) {
            best = Math.max(best, Math.min(height[l], height[r]) * (r - l));
            if (height[l] < height[r]) l++;   // the shorter side limits the area
            else r--;
        }
        return best;
    }
}
```
=== 17
S: `height` describes an elevation map where each bar has width 1. After it rains, return how many units of water are trapped between the bars.
T: `height = [0,1,0,2,1,0,1,3,2,1,2,1]` => `6`
T: `height = [4,2,0,3,2,5]` => `9`
T: `height = [3]` => `0`
A: Water above a bar equals the lower of the tallest bars on its left and right, minus its own height. Two pointers track the running left max and right max; always process the side with the smaller bar, since its limit is already known.
C: new Solution().trap(new int[]{0,1,0,2,1,0,1,3,2,1,2,1})==6 && new Solution().trap(new int[]{4,2,0,3,2,5})==9 && new Solution().trap(new int[]{3})==0
```java
class Solution {
    public int trap(int[] height) {
        int l = 0, r = height.length - 1;
        int leftMax = 0, rightMax = 0, water = 0;
        while (l < r) {
            if (height[l] < height[r]) {
                leftMax = Math.max(leftMax, height[l]);
                water += leftMax - height[l++];
            } else {
                rightMax = Math.max(rightMax, height[r]);
                water += rightMax - height[r--];
            }
        }
        return water;
    }
}
```
=== 18
S: Remove duplicates from a sorted array in place so each value appears once, keeping the relative order. Return `k`, the number of unique values; the first `k` slots must hold them.
T: `nums = [1,1,2]` => `2, nums = [1,2,_]`
T: `nums = [0,0,1,1,1,2,2,3,3,4]` => `5, nums = [0,1,2,3,4,_,_,_,_,_]`
A: A slow pointer marks where the next unique value goes; a fast pointer scans. Whenever the scanned value differs from the last kept one, copy it to the slow position.
C: { int[] a = {1,1,2}; int k = new Solution().removeDuplicates(a); int[] b = {0,0,1,1,1,2,2,3,3,4}; int k2 = new Solution().removeDuplicates(b); return k == 2 && a[0] == 1 && a[1] == 2 && k2 == 5 && A(Arrays.copyOf(b, k2)).equals("[0,1,2,3,4]"); }
```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;
        int k = 1;                              // next write position
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[k - 1]) nums[k++] = nums[i];
        }
        return k;
    }
}
```
=== 19
S: Move every `0` in the array to the end while keeping the order of the non-zero elements. Do it in place.
T: `nums = [0,1,0,3,12]` => `[1,3,12,0,0]`
T: `nums = [0]` => `[0]`
T: `nums = [1,0,0,2]` => `[1,2,0,0]`
A: Keep a write index for the next non-zero value. Scan the array, swapping each non-zero element into the write position. Zeros are pushed back automatically.
C: { int[] a = {0,1,0,3,12}; new Solution().moveZeroes(a); int[] b = {1,0,0,2}; new Solution().moveZeroes(b); return A(a).equals("[1,3,12,0,0]") && A(b).equals("[1,2,0,0]"); }
```java
class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;
        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) {
                int tmp = nums[write];
                nums[write++] = nums[read];
                nums[read] = tmp;
            }
        }
    }
}
```
=== 20
S: Both strings are typed into editors where `#` acts as a backspace (it does nothing on empty text). Return whether the two strings end up equal.
T: `s = "ab#c", t = "ad#c"` => `true`
T: `s = "ab##", t = "c#d#"` => `true`
T: `s = "a#c", t = "b"` => `false`
A: Walk both strings from the end. For each, skip characters that are cancelled by a `#` (count pending backspaces), then compare the next real characters. No stacks or rebuilt strings, so O(1) space.
C: new Solution().backspaceCompare("ab#c","ad#c") && new Solution().backspaceCompare("ab##","c#d#") && !new Solution().backspaceCompare("a#c","b")
```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1, j = t.length() - 1;
        while (true) {
            i = nextValid(s, i);
            j = nextValid(t, j);
            if (i < 0 || j < 0) return i < 0 && j < 0;
            if (s.charAt(i) != t.charAt(j)) return false;
            i--; j--;
        }
    }

    // index of the next character (going left) that survives the backspaces, or -1
    private int nextValid(String str, int i) {
        int skip = 0;
        while (i >= 0) {
            if (str.charAt(i) == '#') { skip++; i--; }
            else if (skip > 0) { skip--; i--; }
            else break;
        }
        return i;
    }
}
```
