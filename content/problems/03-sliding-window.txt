=== 21
S: `prices[i]` is a stock price on day `i`. Choose one day to buy and a later day to sell to maximise profit, and return that profit (0 if no profit is possible).
T: `prices = [7,1,5,3,6,4]` => `5`
T: `prices = [7,6,4,3,1]` => `0`
T: `prices = [2,4,1]` => `2`
A: Track the lowest price seen so far. For each day, the best profit selling today is `price - minSoFar`. Keep the maximum. One pass, O(1) space.
C: new Solution().maxProfit(new int[]{7,1,5,3,6,4})==5 && new Solution().maxProfit(new int[]{7,6,4,3,1})==0 && new Solution().maxProfit(new int[]{2,4,1})==2
```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE, best = 0;
        for (int p : prices) {
            minPrice = Math.min(minPrice, p);
            best = Math.max(best, p - minPrice);
        }
        return best;
    }
}
```
=== 22
S: Return the length of the longest substring of `s` that contains no repeated character.
T: `s = "abcabcbb"` => `3`
T: `s = "bbbbb"` => `1`
T: `s = "pwwkew"` => `3`
A: Sliding window with a table of each character's last seen index. When a character repeats inside the window, jump the window start just past its previous position. The window always holds unique characters.
C: new Solution().lengthOfLongestSubstring("abcabcbb")==3 && new Solution().lengthOfLongestSubstring("bbbbb")==1 && new Solution().lengthOfLongestSubstring("pwwkew")==3 && new Solution().lengthOfLongestSubstring("")==0
```java
import java.util.*;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        Arrays.fill(last, -1);
        int start = 0, best = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (last[c] >= start) start = last[c] + 1; // repeat inside window: shrink
            last[c] = i;
            best = Math.max(best, i - start + 1);
        }
        return best;
    }
}
```
=== 23
S: You may change at most `k` characters of uppercase string `s` to any other letter. Return the length of the longest substring that can be made of one repeated letter.
T: `s = "ABAB", k = 2` => `4`
T: `s = "AABABBA", k = 1` => `4`
T: `s = "AAAA", k = 0` => `4`
A: Keep a window and the count of its most frequent letter. The window is valid while `length - maxCount <= k` (the rest can be replaced). Otherwise slide the left edge. The max count never needs to shrink, because only a larger count can improve the answer.
C: new Solution().characterReplacement("ABAB",2)==4 && new Solution().characterReplacement("AABABBA",1)==4 && new Solution().characterReplacement("AAAA",0)==4
```java
class Solution {
    public int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int left = 0, maxCount = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            maxCount = Math.max(maxCount, ++count[s.charAt(right) - 'A']);
            while (right - left + 1 - maxCount > k) {   // too many replacements needed
                count[s.charAt(left++) - 'A']--;
            }
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
```
=== 24
S: Return `true` if `s2` contains a substring that is a permutation of `s1`.
T: `s1 = "ab", s2 = "eidbaooo"` => `true`
T: `s1 = "ab", s2 = "eidboaoo"` => `false`
T: `s1 = "abc", s2 = "ab"` => `false`
A: Slide a fixed window of length `len(s1)` over `s2`, maintaining letter counts for the window and comparing with the counts of `s1`. Adding the new letter and removing the old one is O(1) per step.
C: new Solution().checkInclusion("ab","eidbaooo") && !new Solution().checkInclusion("ab","eidboaoo") && !new Solution().checkInclusion("abc","ab")
```java
import java.util.*;

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        if (s1.length() > s2.length()) return false;
        int[] need = new int[26], window = new int[26];
        for (int i = 0; i < s1.length(); i++) {
            need[s1.charAt(i) - 'a']++;
            window[s2.charAt(i) - 'a']++;
        }
        if (Arrays.equals(need, window)) return true;
        for (int i = s1.length(); i < s2.length(); i++) {
            window[s2.charAt(i) - 'a']++;                    // enter
            window[s2.charAt(i - s1.length()) - 'a']--;      // leave
            if (Arrays.equals(need, window)) return true;
        }
        return false;
    }
}
```
=== 25
S: Return the smallest substring of `s` that contains every character of `t` (including duplicates). If none exists, return an empty string.
T: `s = "ADOBECODEBANC", t = "ABC"` => `"BANC"`
T: `s = "a", t = "a"` => `"a"`
T: `s = "a", t = "aa"` => `""`
A: Expand the right edge until the window covers all of `t` (tracked with a `missing` counter and a need table). Then shrink from the left while it still covers everything, recording the best window each time.
C: new Solution().minWindow("ADOBECODEBANC","ABC").equals("BANC") && new Solution().minWindow("a","a").equals("a") && new Solution().minWindow("a","aa").equals("")
```java
class Solution {
    public String minWindow(String s, String t) {
        if (t.length() > s.length()) return "";
        int[] need = new int[128];
        for (char c : t.toCharArray()) need[c]++;

        int missing = t.length(), left = 0;
        int bestStart = 0, bestLen = Integer.MAX_VALUE;
        for (int right = 0; right < s.length(); right++) {
            if (need[s.charAt(right)]-- > 0) missing--;     // a needed char entered
            while (missing == 0) {                          // window is valid: try to shrink
                if (right - left + 1 < bestLen) {
                    bestLen = right - left + 1;
                    bestStart = left;
                }
                if (++need[s.charAt(left++)] > 0) missing++; // a needed char left
            }
        }
        return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestStart, bestStart + bestLen);
    }
}
```
=== 26
S: A window of size `k` slides from the left of `nums` to the right, one position at a time. Return the maximum of each window position.
T: `nums = [1,3,-1,-3,5,3,6,7], k = 3` => `[3,3,5,5,6,7]`
T: `nums = [1], k = 1` => `[1]`
T: `nums = [9,11], k = 2` => `[11]`
A: Keep a deque of indices whose values are in decreasing order. Before adding index `i`, drop smaller values from the back (they can never be a max again) and drop the front if it left the window. The front is always the current maximum.
C: A(new Solution().maxSlidingWindow(new int[]{1,3,-1,-3,5,3,6,7},3)).equals("[3,3,5,5,6,7]") && A(new Solution().maxSlidingWindow(new int[]{1},1)).equals("[1]") && A(new Solution().maxSlidingWindow(new int[]{9,11},2)).equals("[11]")
```java
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] result = new int[n - k + 1];
        Deque<Integer> dq = new ArrayDeque<>();      // indices, values decreasing
        for (int i = 0; i < n; i++) {
            if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();       // out of window
            while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) dq.pollLast(); // useless smaller
            dq.offerLast(i);
            if (i >= k - 1) result[i - k + 1] = nums[dq.peekFirst()];
        }
        return result;
    }
}
```
=== 27
S: Find the contiguous subarray of length exactly `k` with the largest average and return that average.
T: `nums = [1,12,-5,-6,50,3], k = 4` => `12.75000`
T: `nums = [5], k = 1` => `5.00000`
A: Compute the sum of the first `k` elements, then slide: add the new element, subtract the one leaving. Track the maximum sum and divide by `k` once at the end.
C: Math.abs(new Solution().findMaxAverage(new int[]{1,12,-5,-6,50,3},4)-12.75)<1e-5 && Math.abs(new Solution().findMaxAverage(new int[]{5},1)-5.0)<1e-5
```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        long sum = 0;
        for (int i = 0; i < k; i++) sum += nums[i];
        long best = sum;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - nums[i - k];     // slide the window by one
            best = Math.max(best, sum);
        }
        return (double) best / k;
    }
}
```
