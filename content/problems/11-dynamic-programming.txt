=== 90
S: You climb a staircase of `n` steps, taking 1 or 2 steps at a time. Return the number of distinct ways to reach the top.
T: `n = 2` => `2`
T: `n = 3` => `3`
T: `n = 5` => `8`
A: The ways to reach step `i` equal the ways to reach `i-1` plus the ways to reach `i-2` (the Fibonacci recurrence). Only the last two values are needed, so space is O(1).
C: new Solution().climbStairs(2)==2 && new Solution().climbStairs(3)==3 && new Solution().climbStairs(5)==8 && new Solution().climbStairs(1)==1
```java
class Solution {
    public int climbStairs(int n) {
        int prev = 1, cur = 1;            // ways to reach step 0 and step 1
        for (int i = 2; i <= n; i++) {
            int next = prev + cur;
            prev = cur;
            cur = next;
        }
        return cur;
    }
}
```
=== 91
S: Each house holds some money, and robbing two adjacent houses triggers an alarm. Return the maximum amount you can rob in one night.
T: `nums = [1,2,3,1]` => `4`
T: `nums = [2,7,9,3,1]` => `12`
T: `nums = [2,1]` => `2`
A: At each house choose the better of skipping it (keep the previous best) or robbing it (value plus the best from two houses back). Two rolling variables are enough.
C: new Solution().rob(new int[]{1,2,3,1})==4 && new Solution().rob(new int[]{2,7,9,3,1})==12 && new Solution().rob(new int[]{2,1})==2
```java
class Solution {
    public int rob(int[] nums) {
        int skip = 0, take = 0;           // best total up to the previous house / the one before
        for (int money : nums) {
            int best = Math.max(take, skip + money);
            skip = take;
            take = best;
        }
        return take;
    }
}
```
=== 92
S: The houses are arranged in a circle, so the first and last houses are adjacent. Return the maximum amount you can rob without robbing two adjacent houses.
T: `nums = [2,3,2]` => `3`
T: `nums = [1,2,3,1]` => `4`
T: `nums = [1,2,3]` => `3`
A: Because the first and last houses cannot both be robbed, the answer is the better of two linear problems: houses `0..n-2` and houses `1..n-1`. Handle a single house separately.
C: new Solution().rob(new int[]{2,3,2})==3 && new Solution().rob(new int[]{1,2,3,1})==4 && new Solution().rob(new int[]{1,2,3})==3 && new Solution().rob(new int[]{1})==1
```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        return Math.max(robLine(nums, 0, n - 2), robLine(nums, 1, n - 1));
    }

    private int robLine(int[] nums, int from, int to) {
        int skip = 0, take = 0;
        for (int i = from; i <= to; i++) {
            int best = Math.max(take, skip + nums[i]);
            skip = take;
            take = best;
        }
        return take;
    }
}
```
=== 93
S: Return the longest palindromic substring of `s`.
T: `s = "babad"` => `"bab"` (`"aba"` is also accepted)
T: `s = "cbbd"` => `"bb"`
T: `s = "a"` => `"a"`
A: Expand around every possible centre: each character (odd length) and each gap between characters (even length). Grow while both ends match and remember the longest span. O(N²) time, O(1) space.
C: new Solution().longestPalindrome("babad").equals("bab") && new Solution().longestPalindrome("cbbd").equals("bb") && new Solution().longestPalindrome("a").equals("a")
```java
class Solution {
    public String longestPalindrome(String s) {
        int start = 0, maxLen = 1;
        for (int center = 0; center < s.length(); center++) {
            int odd = expand(s, center, center);
            int even = expand(s, center, center + 1);
            int len = Math.max(odd, even);
            if (len > maxLen) {
                maxLen = len;
                start = center - (len - 1) / 2;
            }
        }
        return s.substring(start, start + maxLen);
    }

    private int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return r - l - 1;                 // length of the palindrome found
    }
}
```
=== 94
S: Letters are encoded as `A=1 ... Z=26`. Given a digit string `s`, return the number of ways to decode it into letters.
T: `s = "12"` => `2` ("AB" or "L")
T: `s = "226"` => `3`
T: `s = "06"` => `0`
A: `dp[i]` is the number of ways to decode the first `i` characters. A single digit adds `dp[i-1]` if it is 1-9; a two-digit number 10-26 adds `dp[i-2]`. Keep only the last two values.
C: new Solution().numDecodings("12")==2 && new Solution().numDecodings("226")==3 && new Solution().numDecodings("06")==0 && new Solution().numDecodings("10")==1
```java
class Solution {
    public int numDecodings(String s) {
        int prev2 = 1, prev1 = s.charAt(0) == '0' ? 0 : 1;   // dp[0], dp[1]
        for (int i = 2; i <= s.length(); i++) {
            int cur = 0;
            if (s.charAt(i - 1) != '0') cur += prev1;                    // single digit 1-9
            int two = Integer.parseInt(s.substring(i - 2, i));
            if (two >= 10 && two <= 26) cur += prev2;                    // pair 10-26
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```
=== 95
S: Given coin denominations and a target `amount`, return the fewest coins needed to make that amount, or -1 if it cannot be made. You have unlimited coins of each kind.
T: `coins = [1,2,5], amount = 11` => `3` (5 + 5 + 1)
T: `coins = [2], amount = 3` => `-1`
T: `coins = [1], amount = 0` => `0`
A: Bottom-up DP: `dp[a]` is the minimum coins for amount `a`. For each amount try every coin: `dp[a] = min(dp[a - coin] + 1)`. Initialise with a value larger than any answer to mark unreachable amounts.
C: new Solution().coinChange(new int[]{1,2,5},11)==3 && new Solution().coinChange(new int[]{2},3)==-1 && new Solution().coinChange(new int[]{1},0)==0
```java
import java.util.*;

class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);               // "infinity"
        dp[0] = 0;
        for (int a = 1; a <= amount; a++) {
            for (int coin : coins) {
                if (coin <= a) dp[a] = Math.min(dp[a], dp[a - coin] + 1);
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```
=== 96
S: Return the length of the longest strictly increasing subsequence of `nums` (elements keep their order but need not be adjacent).
T: `nums = [10,9,2,5,3,7,101,18]` => `4` ([2,3,7,101])
T: `nums = [0,1,0,3,2,3]` => `4`
T: `nums = [7,7,7,7]` => `1`
A: Patience sorting: keep `tails[k]`, the smallest possible last value of an increasing subsequence of length `k+1`. For each number, binary search the first tail that is at least it and replace that tail (or append). The size of `tails` is the answer.
C: new Solution().lengthOfLIS(new int[]{10,9,2,5,3,7,101,18})==4 && new Solution().lengthOfLIS(new int[]{0,1,0,3,2,3})==4 && new Solution().lengthOfLIS(new int[]{7,7,7,7})==1
```java
import java.util.*;

class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int x : nums) {
            int i = Arrays.binarySearch(tails, 0, size, x);
            if (i < 0) i = -(i + 1);              // insertion point = first tail >= x
            tails[i] = x;
            if (i == size) size++;                // extended the longest subsequence
        }
        return size;
    }
}
```
=== 97
S: Return whether string `s` can be split into a sequence of one or more words from the dictionary `wordDict`. Words may be reused.
T: `s = "leetcode", wordDict = ["leet","code"]` => `true`
T: `s = "applepenapple", wordDict = ["apple","pen"]` => `true`
T: `s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]` => `false`
A: `dp[i]` is true if the first `i` characters can be segmented. For each `i`, look for a split point `j` where `dp[j]` is true and `s[j..i]` is a dictionary word. Put the dictionary in a `HashSet` for O(1) lookups.
C: new Solution().wordBreak("leetcode",Arrays.asList("leet","code")) && new Solution().wordBreak("applepenapple",Arrays.asList("apple","pen")) && !new Solution().wordBreak("catsandog",Arrays.asList("cats","dog","sand","and","cat"))
```java
import java.util.*;

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;                                       // empty prefix
        for (int i = 1; i <= s.length(); i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && words.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```
