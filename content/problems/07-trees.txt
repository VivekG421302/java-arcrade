=== 56
S: Return the diameter of a binary tree: the number of edges on the longest path between any two nodes. The path may or may not pass through the root.
T: `root = [1,2,3,4,5]` => `3`
T: `root = [1,2]` => `1`
A: For each node, the longest path through it is `height(left) + height(right)`. Compute heights bottom-up in one DFS and update a global best as you go.
C: new Solution().diameterOfBinaryTree(T(1,2,3,4,5))==3 && new Solution().diameterOfBinaryTree(T(1,2))==1 && new Solution().diameterOfBinaryTree(T(1))==0
```java
class Solution {
    private int best = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        height(root);
        return best;
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        int left = height(node.left), right = height(node.right);
        best = Math.max(best, left + right);   // path bending at this node
        return 1 + Math.max(left, right);
    }
}
```

S: Return whether a binary tree is height-balanced: for every node, the heights of its left and right subtrees differ by at most 1.
T: `root = [3,9,20,null,null,15,7]` => `true`
T: `root = [1,2,2,3,3,null,null,4,4]` => `false`
T: `root = []` => `true`
A: Compute heights bottom-up and return -1 as soon as any subtree is unbalanced, so each node is processed once instead of recomputing heights at every level.
C: new Solution().isBalanced(T(3,9,20,null,null,15,7)) && !new Solution().isBalanced(T(1,2,2,3,3,null,null,4,4)) && new Solution().isBalanced(null)
```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    // returns the height, or -1 if the subtree is unbalanced
    private int height(TreeNode node) {
        if (node == null) return 0;
        int left = height(node.left);
        if (left == -1) return -1;
        int right = height(node.right);
        if (right == -1 || Math.abs(left - right) > 1) return -1;
        return 1 + Math.max(left, right);
    }
}
```

S: In a binary search tree, return the lowest common ancestor of two given nodes: the deepest node that has both as descendants (a node counts as a descendant of itself).
T: `root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8` => `6`
T: `root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4` => `2`
A: Use the BST ordering. If both values are smaller than the current node, go left; if both are larger, go right; otherwise the current node is where the paths split, so it is the LCA. Iterative, O(H).
C: { TreeNode root = T(6,2,8,0,4,7,9,null,null,3,5); TreeNode two = root.left, eight = root.right, four = root.left.right; return new Solution().lowestCommonAncestor(root,two,eight)==root && new Solution().lowestCommonAncestor(root,two,four)==two; }

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        TreeNode node = root;
        while (node != null) {
            if (p.val < node.val && q.val < node.val) node = node.left;
            else if (p.val > node.val && q.val > node.val) node = node.right;
            else return node;                    // split point (or one of them)
        }
        return null;
    }
}
```

S: Return the level-order traversal of a binary tree: a list of lists, where each inner list holds one level's values from left to right.
T: `root = [3,9,20,null,null,15,7]` => `[[3],[9,20],[15,7]]`
T: `root = [1]` => `[[1]]`
T: `root = []` => `[]`
A: Breadth-first search with a queue. Process exactly `queue.size()` nodes per round so each round is one level, adding children for the next round.
C: S(new Solution().levelOrder(T(3,9,20,null,null,15,7))).equals("[[3],[9,20],[15,7]]") && S(new Solution().levelOrder(T(1))).equals("[[1]]") && S(new Solution().levelOrder(null)).equals("[]")
```java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();                 // nodes on this level
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            result.add(level);
        }
        return result;
    }
}
```

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> view = new ArrayList<>();
        if (root == null) return view;
        Queue<TreeNode> queue = new ArrayDeque<>();
```

S: A node `X` is "good" if no node on the path from the root to `X` has a value greater than `X`. Return the number of good nodes in the tree.
T: `root = [3,1,4,3,null,1,5]` => `4`
T: `root = [3,3,null,4,2]` => `3`
T: `root = [1]` => `1`
A: DFS carrying the maximum value seen on the path so far. A node is good when its value is at least that maximum; then pass the updated maximum to its children.
C: new Solution().goodNodes(T(3,1,4,3,null,1,5))==4 && new Solution().goodNodes(T(3,3,null,4,2))==3 && new Solution().goodNodes(T(1))==1

```java
class Solution {
    public int goodNodes(TreeNode root) {
        return dfs(root, Integer.MIN_VALUE);
    }

    private int dfs(TreeNode node, int maxSoFar) {
        if (node == null) return 0;
        int good = node.val >= maxSoFar ? 1 : 0;
        int newMax = Math.max(maxSoFar, node.val);
        return good + dfs(node.left, newMax) + dfs(node.right, newMax);
    }
```

S: Return the `k`-th smallest value (1-indexed) in a binary search tree.
T: `root = [3,1,4,null,2], k = 1` => `1`
T: `root = [5,3,6,2,4,null,null,1], k = 3` => `3`
A: In-order traversal of a BST visits values in ascending order. Walk it iteratively with a stack and stop at the `k`-th node, which costs O(H + K).
C: new Solution().kthSmallest(T(3,1,4,null,2),1)==1 && new Solution().kthSmallest(T(5,3,6,2,4,null,null,1),3)==3 && new Solution().kthSmallest(T(5,3,6,2,4,null,null,1),6)==6
```java
import java.util.*;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode node = root;
        while (node != null || !stack.isEmpty()) {
            while (node != null) {            // go as far left as possible
                stack.push(node);
                node = node.left;
            }
            node = stack.pop();
            if (--k == 0) return node.val;    // the k-th in-order node
            node = node.right;
        }
        throw new IllegalArgumentException("k is larger than the tree size");
    }
}
```

S: Given the preorder and inorder traversals of a binary tree with unique values, rebuild and return the tree.
T: `preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]` => `[3,9,20,null,null,15,7]`
T: `preorder = [-1], inorder = [-1]` => `[-1]`
A: The first preorder value is the root. Its position in the inorder array splits left and right subtrees. A map from value to inorder index gives O(1) splits, and a moving preorder pointer picks each next root.
C: TS(new Solution().buildTree(new int[]{3,9,20,15,7},new int[]{9,3,15,20,7})).equals("[3,9,20,null,null,15,7]") && TS(new Solution().buildTree(new int[]{-1},new int[]{-1})).equals("[-1]")
```java
import java.util.*;

class Solution {
    private int pre = 0;
    private Map<Integer, Integer> inIndex = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        pre = 0;
        for (int i = 0; i < inorder.length; i++) inIndex.put(inorder[i], i);
        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int lo, int hi) {
        if (lo > hi) return null;
        TreeNode root = new TreeNode(preorder[pre++]);
        int mid = inIndex.get(root.val);                 // split point in inorder
        root.left = build(preorder, lo, mid - 1);
        root.right = build(preorder, mid + 1, hi);
        return root;
    }
}
```

S: A path in a binary tree is any sequence of connected nodes, going through each node at most once, and it need not pass through the root. Return the maximum sum of node values over all non-empty paths.
T: `root = [1,2,3]` => `6`
T: `root = [-10,9,20,null,null,15,7]` => `42`
T: `root = [-3]` => `-3`
A: For each node compute the best downward path starting there (`node + max(0, bestLeft, bestRight)`). The best path bending at the node is `node + max(0, left) + max(0, right)`; track the global maximum. Negative branches are ignored.
C: new Solution().maxPathSum(T(1,2,3))==6 && new Solution().maxPathSum(T(-10,9,20,null,null,15,7))==42 && new Solution().maxPathSum(T(-3))==-3
```java
class Solution {
    private int best;

    public int maxPathSum(TreeNode root) {
        best = Integer.MIN_VALUE;
        gain(root);
        return best;
    }

    // best sum of a downward path that starts at this node
    private int gain(TreeNode node) {
        if (node == null) return 0;
        int left = Math.max(0, gain(node.left));     // drop negative branches
        int right = Math.max(0, gain(node.right));
        best = Math.max(best, node.val + left + right); // path bending here
        return node.val + Math.max(left, right);
    }
}
```

S: Design `serialize` and `deserialize` for a binary tree: convert the tree to a string and rebuild exactly the same tree from that string. You choose the format.
T: `root = [1,2,3,null,null,4,5]` => `serialized "1,2,#,#,3,4,#,#,5,#,#" and restored to [1,2,3,null,null,4,5]`
T: `root = []` => `serialized "#" and restored to []`
A: Pre-order DFS, writing `#` for null children. Because pre-order plus explicit nulls is unambiguous, deserialization consumes the tokens in the same order and rebuilds recursively.
C: { TreeCodec c = new TreeCodec(); String s = c.serialize(T(1,2,3,null,null,4,5)); return s.equals("1,2,#,#,3,4,#,#,5,#,#") && TS(c.deserialize(s)).equals("[1,2,3,null,null,4,5]") && c.serialize(null).equals("#") && c.deserialize("#") == null; }
```java
import java.util.*;

class TreeCodec {
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        write(root, sb);
        return sb.toString();
    }

    private void write(TreeNode node, StringBuilder sb) {
        if (sb.length() > 0) sb.append(',');
        if (node == null) { sb.append('#'); return; }
        sb.append(node.val);
        write(node.left, sb);
        write(node.right, sb);
    }

    public TreeNode deserialize(String data) {
        Queue<String> tokens = new ArrayDeque<>(Arrays.asList(data.split(",")));
        return read(tokens);
    }

    private TreeNode read(Queue<String> tokens) {
        String t = tokens.poll();
        if (t.equals("#")) return null;
        TreeNode node = new TreeNode(Integer.parseInt(t));
        node.left = read(tokens);
        node.right = read(tokens);
        return node;
    }
}
```
