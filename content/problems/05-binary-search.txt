=== 35
S: `nums` is sorted ascending with distinct values. Return the index of `target`, or -1 if it is absent, in O(log N).
T: `nums = [-1,0,3,5,9,12], target = 9` => `4`
T: `nums = [-1,0,3,5,9,12], target = 2` => `-1`
A: Keep a low and high bound. Compare the middle element with the target and discard the half that cannot contain it. Compute `mid` as `lo + (hi - lo) / 2` to avoid overflow.
C: new Solution().search(new int[]{-1,0,3,5,9,12},9)==4 && new Solution().search(new int[]{-1,0,3,5,9,12},2)==-1 && new Solution().search(new int[]{5},5)==0
```java
class Solution {
    public int search(int[] nums, int target) {
        int lo = 0, hi = nums.length - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return -1;
    }
}
```
=== 36
S: Each row of the matrix is sorted, and the first number of a row is greater than the last number of the previous row. Return whether `target` is in the matrix, in O(log(M·N)).
T: `matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3` => `true`
T: `matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13` => `false`
A: The matrix behaves like one sorted array of `rows * cols` elements. Binary search over the virtual index and convert with `row = mid / cols`, `col = mid % cols`.
C: { int[][] m = {{1,3,5,7},{10,11,16,20},{23,30,34,60}}; return new Solution().searchMatrix(m,3) && !new Solution().searchMatrix(m,13) && new Solution().searchMatrix(m,60) && !new Solution().searchMatrix(m,0); }
```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int rows = matrix.length, cols = matrix[0].length;
        int lo = 0, hi = rows * cols - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int val = matrix[mid / cols][mid % cols];   // map flat index to cell
            if (val == target) return true;
            if (val < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return false;
    }
}
```
=== 37
S: Koko has `h` hours to eat all banana piles. At speed `k` bananas/hour she eats from one pile per hour (finishing a smaller pile wastes the rest of that hour). Return the minimum integer `k` that lets her finish within `h` hours.
T: `piles = [3,6,7,11], h = 8` => `4`
T: `piles = [30,11,23,4,20], h = 5` => `30`
T: `piles = [30,11,23,4,20], h = 6` => `23`
A: Binary search on the answer `k` between 1 and the largest pile. For a candidate `k`, the hours needed are the sum of `ceil(pile / k)`. Feasibility is monotonic, so find the smallest feasible `k`.
C: new Solution().minEatingSpeed(new int[]{3,6,7,11},8)==4 && new Solution().minEatingSpeed(new int[]{30,11,23,4,20},5)==30 && new Solution().minEatingSpeed(new int[]{30,11,23,4,20},6)==23
```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int lo = 1, hi = 0;
        for (int p : piles) hi = Math.max(hi, p);
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (hoursNeeded(piles, mid) <= h) hi = mid;   // fast enough: try slower
            else lo = mid + 1;
        }
        return lo;
    }

    private long hoursNeeded(int[] piles, int k) {
        long hours = 0;
        for (int p : piles) hours += (p + k - 1) / k;       // ceil(p / k)
        return hours;
    }
}
```

S: A sorted array of distinct values was rotated at an unknown pivot (for example `[0,1,2,4,5,6,7]` became `[4,5,6,7,0,1,2]`). Return the minimum element in O(log N).
T: `nums = [3,4,5,1,2]` => `1`
T: `nums = [4,5,6,7,0,1,2]` => `0`
T: `nums = [11,13,15,17]` => `11`
A: Compare `nums[mid]` with `nums[hi]`. If mid is larger, the minimum is to its right; otherwise it is at mid or to its left. Narrow until the bounds meet.
C: new Solution().findMin(new int[]{3,4,5,1,2})==1 && new Solution().findMin(new int[]{4,5,6,7,0,1,2})==0 && new Solution().findMin(new int[]{11,13,15,17})==11
```java
class Solution {
    public int findMin(int[] nums) {
        int lo = 0, hi = nums.length - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] > nums[hi]) lo = mid + 1;   // minimum is in the right half
            else hi = mid;                            // mid could be the minimum
        }
        return nums[lo];
    }
}
```
=== 39
S: A sorted array of distinct values was rotated at an unknown pivot. Return the index of `target`, or -1 if it is not present, in O(log N).
T: `nums = [4,5,6,7,0,1,2], target = 0` => `4`
T: `nums = [4,5,6,7,0,1,2], target = 3` => `-1`
T: `nums = [1], target = 0` => `-1`
A: At every step one half around `mid` is sorted. Check whether the target lies inside the sorted half; if so search it, otherwise search the other half.
C: new Solution().search(new int[]{4,5,6,7,0,1,2},0)==4 && new Solution().search(new int[]{4,5,6,7,0,1,2},3)==-1 && new Solution().search(new int[]{1},0)==-1 && new Solution().search(new int[]{3,1},1)==1
```java
class Solution {
    public int search(int[] nums, int target) {
        int lo = 0, hi = nums.length - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] == target) return mid;
            if (nums[lo] <= nums[mid]) {                       // left half is sorted
                if (nums[lo] <= target && target < nums[mid]) hi = mid - 1;
                else lo = mid + 1;
            } else {                                           // right half is sorted
                if (nums[mid] < target && target <= nums[hi]) lo = mid + 1;
                else hi = mid - 1;
            }
        }
        return -1;
    }
}
```

S: Design a key-value store where each key keeps multiple values with increasing timestamps. `set(key, value, timestamp)` stores a value; `get(key, timestamp)` returns the value whose timestamp is the largest one not greater than the query, or an empty string if none exists.
T: `set("foo","bar",1), get("foo",1), get("foo",3)` => `"bar", "bar"`
T: `set("foo","bar2",4), get("foo",4), get("foo",5)` => `"bar2", "bar2"`
T: `get("foo",0), get("baz",1)` => `"", ""`
A: Store a `TreeMap<Integer, String>` per key and use `floorEntry(timestamp)` for the lookup, which is O(log N). With strictly increasing timestamps an `ArrayList` plus manual binary search gives O(1) set.
C: { TimeMap t = new TimeMap(); t.set("foo","bar",1); boolean a = t.get("foo",1).equals("bar") && t.get("foo",3).equals("bar"); t.set("foo","bar2",4); return a && t.get("foo",4).equals("bar2") && t.get("foo",5).equals("bar2") && t.get("foo",0).equals("") && t.get("baz",1).equals(""); }
```java
import java.util.*;

class TimeMap {
    private final Map<String, TreeMap<Integer, String>> store = new HashMap<>();

    public void set(String key, String value, int timestamp) {
        store.computeIfAbsent(key, k -> new TreeMap<>()).put(timestamp, value);
    }

    public String get(String key, int timestamp) {
        TreeMap<Integer, String> history = store.get(key);
        if (history == null) return "";
        Map.Entry<Integer, String> e = history.floorEntry(timestamp); // greatest ts <= timestamp
        return e == null ? "" : e.getValue();
    }
}
```

S: Given two sorted arrays `nums1` and `nums2`, return the median of all their elements combined. The running time must be O(log(min(M, N))).
T: `nums1 = [1,3], nums2 = [2]` => `2.0`
T: `nums1 = [1,2], nums2 = [3,4]` => `2.5`
T: `nums1 = [], nums2 = [1]` => `1.0`
A: Binary search a partition of the shorter array so that the left halves of both arrays together hold half the elements and every left value is at most every right value. Then the median comes from the four values around the cut.
C: new Solution().findMedianSortedArrays(new int[]{1,3},new int[]{2})==2.0 && new Solution().findMedianSortedArrays(new int[]{1,2},new int[]{3,4})==2.5 && new Solution().findMedianSortedArrays(new int[]{},new int[]{1})==1.0
```java
class Solution {
    public double findMedianSortedArrays(int[] a, int[] b) {
        if (a.length > b.length) return findMedianSortedArrays(b, a); // search the shorter one
        int m = a.length, n = b.length;
        int lo = 0, hi = m, leftSize = (m + n + 1) / 2;
        while (lo <= hi) {
            int i = (lo + hi) / 2, j = leftSize - i;           // cut positions in a and b
            int aLeft  = i == 0 ? Integer.MIN_VALUE : a[i - 1];
            int aRight = i == m ? Integer.MAX_VALUE : a[i];
            int bLeft  = j == 0 ? Integer.MIN_VALUE : b[j - 1];
            int bRight = j == n ? Integer.MAX_VALUE : b[j];
            if (aLeft <= bRight && bLeft <= aRight) {
                if ((m + n) % 2 == 1) return Math.max(aLeft, bLeft);
                return (Math.max(aLeft, bLeft) + Math.min(aRight, bRight)) / 2.0;
            } else if (aLeft > bRight) hi = i - 1;
            else lo = i + 1;
        }
        throw new IllegalArgumentException("arrays must be sorted");
    }
}
```
=== 42
S: In a sorted array, return the `[first, last]` indices of `target`, or `[-1,-1]` if it does not occur. It must run in O(log N).
T: `nums = [5,7,7,8,8,10], target = 8` => `[3,4]`
T: `nums = [5,7,7,8,8,10], target = 6` => `[-1,-1]`
T: `nums = [], target = 0` => `[-1,-1]`
A: Run a binary search twice: once for the first index whose value is at least `target`, and once for the first index whose value is strictly greater. The range is `[first, firstGreater - 1]`, valid only if the first position holds the target.
C: A(new Solution().searchRange(new int[]{5,7,7,8,8,10},8)).equals("[3,4]") && A(new Solution().searchRange(new int[]{5,7,7,8,8,10},6)).equals("[-1,-1]") && A(new Solution().searchRange(new int[]{},0)).equals("[-1,-1]")
```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int first = bound(nums, target, false);
        if (first == nums.length || nums[first] != target) return new int[]{-1, -1};
        int last = bound(nums, target, true) - 1;
        return new int[]{first, last};
    }

    // upper=false: first index with value >= t; upper=true: first index with value > t
    private int bound(int[] a, int t, boolean upper) {
        int lo = 0, hi = a.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] < t || (upper && a[mid] == t)) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
```
